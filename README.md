# Coastal-Urban-Resilience
🌍 Coastal Climate & Vegetation Monitoring using Google Earth Engine
This project uses Google Earth Engine (GEE) to analyze land surface temperature (LST), vegetation health (NDVI), and land cover patterns along the Indian coastal belt. It also includes interactive visualizations and statistical assessments of climate risk across this region.

Datasets Used:
- MODIS LST (MOD11A1 v061) – Daily land surface temperature.
- MODIS NDVI (MOD13A2 v006) – Bi-weekly NDVI to assess vegetation.
- ESA WorldCover v100 – Land cover classification.
- FAO/GAUL Admin Boundaries (optional) – Administrative overlays for contextual analysis.

📊 Outputs & Analysis
- Statistical Summaries:
  Mean LST (°C), NDVI, and land cover class values across the coastal region.
- Time-Series Charts:
  LST and NDVI variations over the year.
- Histogram Charts:
  Distribution of LST, NDVI, and land cover types.

🖥️ Visualization Layers
- LST Map: Heatmap ranging from 20°C to 50°C using a blue-yellow-red color ramp.
- NDVI Map: Vegetation index from 0 to 1 using a brown-green color palette.
- Land Cover Map: Multi-class visualization with distinct color codes.
